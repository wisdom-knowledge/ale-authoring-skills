# 将要求写成稳定判据

## 三步选择检查路径

### 1. 先找非视觉证据

按本题文件和已核对的工具考虑原生文本、表格值、对象属性、几何关系、结构与可复算结果。
分别说明“如何找到对象”和“如何判断属性”。最终画面要求不能仅凭源文件中存在一个对象就判通过，
还要覆盖其是否出现在交付结果、可见性及与该属性有关的遮挡。

记录真实可用的工具入口及证据。只知道理论上可算、却没有对应工具时，记录工具缺口，
不把客观要求改成主观要求，也不声称可以确定性执行。访谈时可用宿主工具分析材料；
评分实现则要核对目标评估环境允许的工具和版本，不能把访谈环境的能力直接当成评分器能力。

### 2. 用金标解释已有主观要求，再试非视觉路径

先把题面要求引用出来，再请专家指出金标中体现该要求的属性与不合格边界。
例如“信息完整”可收敛成题面规定的字段覆盖；“结构可编辑”可收敛成原生对象与属性。
“风格协调”不能无依据换成颜色数量、留白比例或某个金标坐标。

允许从金标取得已有要求所指的目标信息，但需区分目标值、样本测量值和合格边界。
单个金标的测量值不能推出容差。专家明确解释的边界应记录原话与日期，并检查其是否
误杀题面允许的其他解法。未确认的容差、阈值和代理指标不能进入正式标准。
数字要有单位、口径和来源；版本不兼容或精度不明时先核对，不编造所谓行业常规。

### 3. 保留必要的限定视觉 Judge

确实依赖视觉质量且无法无损改成非视觉检查时，固定检查对象、证据视图和单一问题：

- 一个问题只检查一个任务相关属性；通过和失败各写可观察的条件，不问“整体好不好”。
- 固定一致的取证规则，不按某一份 rollout 的坐标或对象顺序裁图。
- 依赖对象存在的检查写明前提；对象确实缺失与取证失败分开处理。
- 模型说不准不能默认通过。保留不确定状态；评分器如何映射该状态需在其接口中明确。
- 不向 Judge 提供“这是 SOTA/弱模型”、期望总分或让某个模型赢的提示。
- 把金标帮助澄清的目标属性与合格边界展开进判据，不仅写“与金标一致”。
  不默认评分器能访问访谈中的金标、截图或临时文件；需要的输入资产应有明确的交付与获取方式。

## 模型依赖与标签

| 实际检查路径 | 内部 dependency | 预算处理 |
| --- | --- | --- |
| 已核实的确定性取证和计算，无模型参与 | code | 不计入模型权重 |
| 文本或图像 LLM 直接判断 | judge | 整条计入 |
| Agent 找对象、取证或判断 | agent | 整条计入 |
| 模型定位/OCR/语义判断后再做计算，或同条混有模型判断 | mixed | 整条计入 |
| 工具缺口、未核实的调用链或未知模型依赖 | unknown | 报上下界，不放行预算 |

上述分类用于计算模型依赖的评分权重占比，不按条目数或子条件数计算。
OCR 是否属于模型依赖以实际实现为准；名字叫工具或输出数字不能证明无模型。
`label` 表示判据性质，不替代调用链证据：有明确客观规则但缺工具时可保持
`deterministic`，内部依赖必须为 `unknown`；不能据标签报告已实现。

## 简短访谈示例

### 金标额外布局

Query 只要求包含完整标题。专家说：“SOTA 和金标都把标题放左上，另一份放在中间。”

答：“标题位置在题面中没有限制，这一点先不计分。我看题面要求标题完整；两份标题的文字是否都齐全？”

保留内容完整性，不能新增左上角要求。若专家随后提供 Input 的指定布局条款，再基于条款重新判断。

### 可复算内容

Query 要求报告写明销售总额，Input 是 sales.csv。专家说：“这份数对，另一份数不对。”

先按 Input 规定的范围、单位和公式复算；有退款/去重口径歧义时，只追问这一项。
正式标准规定同一计算口径，不写“等于 SOTA 的数字”。金标可辅助核对，不能代替原始计算。

### 主观要求

Query 要求标题清晰。专家说：“金标留白大概 30%，就规定至少 30%。”

先问：“这里影响标题清晰的是遮挡、对比还是字太小？能指出具体位置吗？”
不能直接采用留白比例。若只收敛出“无遮挡”，它只覆盖遮挡这个子问题，
不能宣称覆盖全部清晰度；剩余属性继续澄清或保留限定 Judge。

### 优劣反转与未知

评测模型更好时正常按其优势追问，不把标签交换成 SOTA。日志声称已导出而未见文件，
只能记录未核验，不能归入“双方都没做到”。经核实的反向优势与共同成功仍进入必要覆盖。
